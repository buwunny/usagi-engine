# Glossary

| Term | Meaning |
|---|---|
| agari | a win |
| akadora | red five, worth +1 han |
| ankan | closed kan (four of a kind from your own hand) |
| atozuke | winning on a yaku that only the winning tile provides (allowed on Tenhou) |
| chankan | robbing a kan: ron on a tile added by kakan |
| chi | calling a sequence from the previous player's discard |
| chiitoitsu | seven pairs |
| daiminkan | open kan called from a discard |
| dora | bonus tile; the tile after the dora indicator |
| fu | "minipoints" for hand shape |
| furiten | can't ron (see reference/tenhou-rules.md) |
| han | the main unit of hand value |
| hanchan | a full game (East + South rounds) |
| honba | repeat counter, +300 per win |
| ippatsu | win within one go-around of riichi |
| jantou | the pair in a standard hand |
| kakan / shouminkan | adding a fourth tile to your pon |
| kan / kantsu | four of a kind (counts as one set) |
| kawa | discard pond |
| kokushi musou | thirteen orphans |
| koutsu | triplet |
| kuikae | swap-calling: discarding the called tile (or its other end) right after a call; forbidden on Tenhou |
| kuitan | open tanyao, allowed on Tenhou |
| machi | wait |
| mangan | limit hand: 5 han (or 4/40, 3/70), 8000 for non-dealer |
| menzen | closed hand |
| mentsu | set (sequence or triplet) |
| naki | calling (chi, pon, kan) |
| oya / ko | dealer / non-dealer |
| pon | calling a triplet |
| renchan | dealer repeat |
| riichi | declaration of a closed tenpai hand |
| rinshan | replacement draw after a kan |
| ron | winning on another player's discard |
| ryuukyoku | draw (no winner) |
| shanten | tiles needed to reach tenpai |
| shuntsu | sequence |
| taatsu | partial set (two tiles one away from a set) |
| tenpai | one tile from winning |
| tobi | going below zero, ends the game on Tenhou |
| tsumo | drawing; also winning by self-draw |
| tsumogiri | discarding the tile you just drew |
| ukeire | tile acceptance: tiles that improve the hand |
| ura dora | hidden dora under the indicators, for riichi winners |
| yaku | scoring pattern; a hand needs at least one to win |
| yakuhai | dragon/seat-wind/round-wind triplet yaku |
| yakuman | limit hand worth 32,000 (non-dealer) |
| yaochuuhai | terminals and honors (13 kinds) |
