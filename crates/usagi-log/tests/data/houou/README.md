# Houou excerpts

Single hands cut from Tenhou Houou logs (made with `tools/excerpt_log.py`,
player names removed) where replaying a month of games found the engine
disagreeing with Tenhou. Each file name says what the hand tests.

- `ankan-on-riichi-wait-not-furiten.mjlog`: another player's closed kan
  of a tile the riichi player waits on doesn't put them in furiten
  (only kokushi may rob a closed kan), so their later ron stands.
