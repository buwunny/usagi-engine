# Sample logs from mjx

These Tenhou mjlog files come from the test resources of
[mjx](https://github.com/mjx-project/mjx) (`tests_cpp/resources/mjlog`),
used under the MIT license in `LICENSE-mjx`. Duplicates were dropped and
`&tw=2` / `+` were removed from file names. Most are real Houou games or
excerpts of them, chosen by the mjx authors for rule edge cases.
